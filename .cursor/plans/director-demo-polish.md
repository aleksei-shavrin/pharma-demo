# Финальная доводка pharma-demo перед показом директору

Согласован 2026-11-06. Исходный идентификатор Cursor: `director_demo_polish_1133d87e`. Рабочая копия — этот файл. Код демо, шкала и календарный план в этой волне не меняются.

Сборка уже отвечает на `http://127.0.0.1:3080`. Этот адрес доступен только на машине, где запущена сборка.

## Граница готовности

- Сборка на `http://127.0.0.1:3080` открывается.
- Маршрут C → D → F идёт по обновлённому письму: видно, куда нажать, какой снимок выбран и как вернуться.
- Блокеров показа в коде нет; расхождения инструкции закрываются текстом комплекта.
- E02 остаётся открытым, пока другой участник не пройдёт комплект и результат не будет записан в раздел «Репетиция (E02)». Волна документации этот пункт не отмечает.

## Вне активной доводки

В [плане работ](../../docs/07-delivery/pharma-demo-call-work-plan.md) чекбоксы **C05** и **E04** остаются пустыми. Оба пункта выведены из доводки демо. Код крошек и правило сравнения периода не меняются.

Без повторной проверки, пока сборка и сценарий не менялись:

- C01, C02–C04, C09–C14: маркер, уведомления, подпись «Изменения к снимку …», три рендера.
- C06: линии `.vis-grid.vis-minor` — границы месяцев. Скрытие не возвращать. Стебли варианта 1 не менять.
- C08 и вид `/schedule` на C: одна прогнозная полоса на `WK-01`…`WK-05`. Лабораторию не повторять. C07 открыт, пока нет макета ОСУП. Продуктовый режим «Базовый план и факт» описан в [demo-v1-schedule-workspace.md](../../docs/05-ux-ui/demo-v1-schedule-workspace.md) §1.5. На ближайший показ вторая полоса не входит.
- F07: кнопки над сайдбаром нет. К диагностике возвращаться только при новом признаке.
- Технический прогон автора 2026-11-06 не закрывает E02.

## Что показал маршрут

Проверено на сборке при снимке D, без повторного замера шкалы и Ганта.

- На странице программы ссылка «Отставание монтажа панелей чистых зон» ведёт на `/programs/PRG-CON?focus=AN-08#project-AN-08`. На снимке C этой строки нет. На обзоре жирный заголовок исключения — «Чистые зоны не готовы к HVAC»; полная фраза там не заголовок.
- «Состав» сохраняет снимок D. Рядом с заголовком есть ссылка «Строительство». Крошки те же, что у программы, и не кликаются.
- С карточки AN-08 ссылка «Строительство» возвращает на программу, снимок не меняется. Прямой адрес `/projects/AN-08` показывает ту же ссылку и строку «Снимок D».
- Карточка оборудования «Панели чистых помещений» не содержит ссылки на проект или программу. Один «Назад» возвращает на AN-08 при том же снимке.
- Пункт «Дашборд» открывает `/` без `?program=`. Снимок остаётся. Чтобы снова увидеть выбранную программу, нужно нажать «Строительство».
- Пустая сессия поднимает снимок A: на программе написано «Открытых проблем программы в этом снимке нет».

Код возврата уже есть: имя программы, «Состав», «Назад», «Дашборд». Отдельная ссылка «к проекту» на оборудовании и кликабельные крошки в волну не входят.

## Принятые решения

- Адрес для человека за этим компьютером: `http://127.0.0.1:3080`. Для другого компьютера этот адрес не открывается. Сетевой адрес неизвестен и в письмо не подставляется.
- Старт: открыть `/`, снять `?program=` повторным нажатием программы, выбрать снимок C. Если открылся A или чужой снимок — снова выбрать C. Запасной сброс в консоли остаётся только для ведущего.
- Восстановление: «Дашборд» → нужный снимок → «Строительство» → «Перейти к программе».
- Для «Состава» и карточки оборудования — отдельные инструкции с названиями экранов, без подсчёта «Назад» после дополнительных переходов.
- Разделы 1–8 walkthrough — ранняя матрица приёмки. Маршрут показа — «Показ портфеля» и комплект репетиции. Даты и DEC-001 в §7–8 не переписывать в этой волне.

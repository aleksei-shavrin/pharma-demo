# Proposal: Портфель, программы и проекты показа (B01–B03, B07–B09, D01–D07, E01–E03)

## Status

Reviewed 2026-11-06. Человек согласовал контракт S0 без изменения требований. Document `status` living specs не меняется до archive. Реализация идёт по этому change.

## Why

Обзор сейчас показывает один `PRJ-01` и восемь направлений. Для показа директору нужны портфель, семь программ из отчёта A01 и переход к проекту с той же проблемой, без новой причинности «поставка панелей вызвала отставание монтажа».

## What Changes

- Read-model портфеля (`PRJ-01` остаётся контейнером завода), семи программ `PRG-*` и 25 проектов аналитика `AN-01`…`AN-25`.
- Принадлежность вехи и видимость на шкале — разные поля. Один ID вехи может входить и в подборку из 12, и в шкалу своей программы.
- Дашборд: подписи портфеля, блок «Состояние по программам», выбор программы без перехода, действие «Перейти к программе».
- Страницы списка программ, дашборда программы, состава и карточки проекта. Пункты сайдбара «Программы» и «Проекты».
- Снимок остаётся в сессии. Выбор программы на обзоре — query `program`. Кнопка «Назад» ходит по истории URL и не откатывает снимок.
- Сценарий показа C → D → F и репетиция E02. E02 отмечается только после прогона с другим участником.

Вне change: E04–E05, F07, полный импорт WBS, расчёт критического пути, замена варианта 1 шкалы, реестры и карточки оборудования/проблем как отдельные экраны.

## Capabilities

### New Capabilities

- `portfolio-program-project`: членство программ и проектов, принадлежность и видимость вех, статусы тонких строк, маршруты, фильтр «Требует внимания», пустая программа и неизвестный ID.

### Modified Capabilities

- `project-status-overview`: правый блок читает программы; дата запуска и статус портфеля остаются агрегатом `PRJ-01`.
- `milestone-readiness`: у вехи одна запись; видимость портфельной подборки не отменяет видимость в программе.
- `demo-v1-architecture-constraints`: проекты аналитика — read-model внутри `PRJ-01`, не Domain WBS и не замена Schedule.

## Impact

- Docs этой волны: ADR-0006, UX дашборда и навигации, narrative, walkthrough. Код API и страниц — после review change.
- Регрессия: C/D «Требуется решение», F `DEC-001`, `MS-PS` `2027-10-06` +21, HVAC, `MS-CLN-PANEL`, `MS-UTL-PWR`.
- Платформа `reference platform`: в E03 подтверждены только маршруты карточек. Поведение шкалы, фильтра и снимка — гипотеза до отдельной проверки.

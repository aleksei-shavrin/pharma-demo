# Demo v1 — сценарий живой демонстрации

Операторская шпаргалка для живого показа **Pharma Demo** потенциальному директору фармацевтического проекта.

Не руководство пользователя. Не архитектурный документ. Не маркетинг.

Держите эту страницу во **второй вкладке**; приложение — в основной.

> **certainty:** assumption — сценарий и числа ниже сверены с DX UI/API-фикстурами на `http://127.0.0.1:3080` (прогон 2026-11-09, login `admin`/`admin`). Это проверка реализации Demo v1, не утверждение о реальном предприятии / GMP.

> и управленческим решением — и честно отличает
> «решение зарегистрировано» от «сроки восстановлены».

### 4. Календарный план — Разделение на 03

| | |
|--|--|
| **Куда** | Сайдбар **Календарный план** (`/schedule`), снимок остаётся **03** |
| **Режимы (основной путь)** | Три иконки: **Таблица** / **Разделение** / **Временная шкала**. По умолчанию нажато **Разделение** (таблица + диаграмма). «Временная шкала» прячет таблицу — в этом эпизоде **не** нажимайте |
| **Сравнение** | Иконки **«Базовый план / прогноз»** (нужно для речи) и **«Базовый план / факт»** (не включать в этой речи) |
| **Масштаб шкалы** | **Приблизить** / **Отдалить** — меняют плотность месяцев на диаграмме; для punch не обязательны |
| **Видно** | Дерево ИСР/работ (полный analyst import; счётчики в шапке порядка сотен строк). Для речи: раскройте ветку с ИСР **8** → **8.2**, работы с прогрессом 0%/40%, ромб вехи; база сверху / прогноз снизу на сравниваемых работах |
| **Сказать** | «Тот же эффект во времени: база остаётся контрольной точкой, прогноз смещён.» |
| **Дальше** | **Дашборд** → **Снимок 06** |

## Иерархия календарного плана

Короткий HVAC-показ выше остаётся. Эпизод можно вставить после шага 3 (на **03**) перед возвратом на Дашборд. Полный текст — [walkthrough](../../03-product/demo-v1-acceptance-walkthrough.md#иерархия-календарного-плана); чеклист-отчёт 2026-11-06 — **historical** замер на другом порту.

> **certainty:** assumption — структура ИСР 8 / 8.2 и смысл сравнения база/прогноз сохранены; абсолютные счетчики строк и порт `:3000` в старых отчётах не использовать как current.

1. Откройте **Календарный план**.
2. Если на кнопке снимка не **03** — выберите **03**. Скажите: «Снимок 03».
3. Режим **Разделение** уже нажат.
4. Найдите / раскройте группу с ИСР **8**, затем **8.2** (имена чистых помещений / отделки). Код ИСР числовой.
5. Предупреждение — иконка; по наведению/фокусу имя вроде «Отставание, …».
6. Сравните полосы база/прогноз на работе с ненулевым прогрессом; сравнение — **«Базовый план / прогноз»**.
7. При необходимости **Приблизить/Отдалить** шкалу, чтобы месяцы читались.
8. Вернитесь на **Дашборд**, продолжайте 03 → 06 → …

## Если директор спросит

| Вопрос | Безопасный ответ |
|--------|------------------|
| Почему ровно **+21** / **+14**? | В Demo v1 это явное правило сценария (BR-004: HVAC/RISK-001 → Production Start). Не полноценный CPM. |
| Это критический путь? | Demo показывает управленческую связку «задержка → готовность к производству». CPM здесь не демонстрируется. |
| Что после решения? | Decision **не** меняет прогноз сам по себе. Улучшение на 07/08 — заранее заданное состояние снимка. |
| Откуда данные? | Подготовленный сценарий снимков **01…19** (2027). Не данные реального предприятия. |
| Это промышленная система? | **Demo v1** для управленческого сценария. Не заявляем GMP/CSV-валидацию продукта. |
| Что за PRT-01? | Внутренний id **портфеля-контейнера**. Реальные проекты — **AN-***. В крошках часто «Портфель 01». |

## Если что-то пошло не так

| Если | Действие |
|------|----------|
| Долгая «Загрузка…» | 1–2 с; иначе F5 в **той же** вкладке |
| Потеряли маршрут | **Дашборд** → нужный снимок **01…08** в селекторе |
| После F5 «не тот» снимок | В той же вкладке восстанавливается последний **успешно загруженный** снимок |
| Новая вкладка / устаревший сохранённый выбор | Начинается с **01** |
| Не туда вошли (логин) | Снова `/login`, **admin** / **admin** |

> F5 в той же вкладке восстанавливает снимок из `sessionStorage` (только канон `01`…`19`). Устаревший/невалидный выбор сбрасывается на **01**.

## Чем закончить показ

Оставайтесь на **03** (punch) или на **08** (residual honesty).

«Мы проследили путь от конкретной задержки оборудования до влияния на дату запуска и управленческого решения. Важно: система не выдаёт само решение за уже достигнутый результат.»

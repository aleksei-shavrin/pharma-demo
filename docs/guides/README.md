# Guides (Diátaxis)

Практические материалы по модели **Diátaxis**.

## Политика папок

> **certainty:** fact
>
> Квадранты (`tutorials/`, `how-to/`, `explanation/`, `reference/`) создаются **только когда появляется первая реальная страница** в квадранте. Сейчас — только этот README, без пустых деревьев.

## Когда что писать

| Квадрант | Вопрос читателя |
|----------|-----------------|
| Tutorials | «Научите меня с нуля» |
| How-to | «Как сделать X» |
| Explanation | «Почему так устроено» |
| Reference | «Точные факты/API» |

Нумерованные разделы `00`–`11` остаются каноном продукта/архитектуры; guides не подменяют ADR и REQ.

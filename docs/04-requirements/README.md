# 04-requirements

Хранилище формальных требований. **Пустой seed:** фиктивные требования не создаются.

## Схема ID

`REQ-<AREA>-NNN`

Примеры AREA (не исчерпывающий список): `AUTH`, `PROJ`, `NFR`, `INT` — вводятся по мере появления реальных требований.

## Правила

- Источник и обоснование обязательны; certainty в теле.
- Шаблоны: [requirement-domain](../_templates/requirement-domain.md), [nfr](../_templates/nfr.md), [use-case](../_templates/use-case.md).
- AI не invent'ит pharma/GMP REQ.

## Содержимое

Пока только индекс. Первые `REQ-*` файлы — после реальных входных данных.

- полоса = прогнозный интервал, **календарные** дни, `endDate` **включительна**;

| id (аналитика) | name | startDate (прогноз) | endDate (прогноз) | status | snapshotId |
|----------------|------|---------------------|-------------------|--------|------------|
| … | … | YYYY-MM-DD | YYYY-MM-DD | Waiting \| OnSchedule \| Delayed \| Completed | … |

### 2. Четыре явные связи

Ровно по одной (или больше при необходимости раскладки) связи каждого типа между работами из п.1:

| type | sourceRef (`work:<id>`) | targetRef (`work:<id>`) |
|------|-------------------------|-------------------------|
| SS | | |
| SF | | |
| FF | | |
| FS | | |

Если в исходнике **нет типа** для какой-либо пары предшественник→последователь — **согласуйте демонстрационный пример** (тип + концы из п.1) для показа стрелки; пометьте его как demo-authored.

Укажите **один `snapshotId`**, на котором остаются только прежние маркеры КТ/поставок (без `work` и без `links`) — для регрессии сценария до G07–G11.

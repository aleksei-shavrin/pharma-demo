### Диагностика

| Факт | Результат |
|------|-----------|
| Код `Sidebar` / `AppShell` | Нет collapse / icon-rail; ширина `--sidebar-width` 240px |
| Токен `sidebar-width-collapsed` | В foundations есть, в runtime не подключён |
| F01 StaticIndicator | `devIndicators.appIsrStatus: false`; иногда мелькает «Hide static indicator» (Next dev) — **не** продукт-кнопка collapse |
| Сборка | Compose `http://localhost:3080` (HOST_PORT 3080), volume `apps/web` |
| Viewport desktop | Сайдбар 240px; кнопок над сайдбаром нет |
| Viewport 1100×800 | Collapse UI по-прежнему нет; сайдбар остаётся 240px |
| Повтор 2026-11-06, 1287px и 1100px, `http://127.0.0.1:3080` | Сайдбар 240px. Над ним только skip-link «Перейти к основному содержимому». Индикатор Next.js не показан. Кнопки collapse нет |
| Повтор 2026-11-06, `next dev` `http://127.0.0.1:3000/` | Обычное окно 1714×1281 и 1100×800: сайдбар 240px, клик по бренду панель не открывает, над хедером только skip-link `top: -32px`. Ширина 390px в эту приёмку не входит |

**Вердикт F07:** остаётся **открытой**. Элемент не воспроизведён. Удалять нечего. Кнопку мобильного меню и skip-link не снимали. Пункт снова открывается, если появится collapse в коде или скрин постановки с этой кнопкой.

Основная навигация в единственном (развёрнутом) состоянии сайдбара работает: Дашборд / Календарный план / регистры / Люди / Документация.

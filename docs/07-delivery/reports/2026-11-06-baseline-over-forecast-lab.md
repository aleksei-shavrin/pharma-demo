# База над прогнозом — лаборатория сравнения

Страница `apps/web/scripts/gantt-interval-lab/compare.html` открыта статическим сервером с корнем `apps/web`. Это не маршрут приложения и не `/schedule`. Адаптер, `schedule-view`, API и `lab.js` C08 не менялись. Модуль `baseline-overlay.ts` адаптер не импортирует. Поставка `dhtmlx-gantt@10.0.3`, `license === mit`. Split и `render_mode` повторно не запускались.

Прогон: `node apps/web/scripts/gantt-interval-lab/run-compare.mjs` из корня репозитория. Скрипт поднимает сервер на `127.0.0.1`, транслирует `baseline-overlay.ts` и открывает страницу в headless Chromium. Юнит-тесты модуля, без DHTMLX: `npx vitest run src/components/schedule/baseline-overlay.test.ts` в `apps/web` — 7 тестов, все прошли.

Экземпляр лаборатории: `row_height` 72, `bar_height` 18. К странице подключен продуктовый `dhtmlx-gantt-adapter.css`. Измеренная высота строки 72px: Community пишет inline height из `row_height`, токен `--ppc-gantt-row-h: 36px` этот прогон не сжал. Painter вызывается после `render`, `close` и `open`, потому что перерисовка заменяет DOM внутри `$task_data`.

`forecastTop` в `baselineBox` — это `getTaskPosition().top`, верх строки, не визуальный верх центрированной полосы. При 72 и 18 формула даёт полосу базы высотой 18px и зазор 4px до прогноза. Если места над прогнозом нет, `height` равен 0 и узел не создаётся.

Данные лаборатории, не снимок продукта. У продукта база на 8.2.2, стрелки на WK, пары «база и зависимость на одной работе» нет. Здесь такая пара собрана только для проверки: `B-src` → FS → `B-base`.

## Вердикт для интегратора

**YES** — overlay можно включать.

Обязательные условия подключения, без правок этой лаборатории: выставить `row_height` и `bar_height` так, чтобы над центрированной прогнозной полосой оставался зазор; после каждой перерисовки и после `open`/`close` заново вызвать `paintBaselineOverlay` на `$task_data`, передавая только видимые задачи и свежий `getTaskPosition`. Иначе узел либо не появится (`height === 0`), либо останется от прошлого кадра. Концы стрелки остаются id прогнозных задач. Модуль по-прежнему не импортируется адаптером, пока интегратор сам его не подключит.

# A06–A09 — маршрут директора

Существующие записи. Новых ID нет. Даты и связи A01–A05 не меняются: `MS-CLN-PANEL` baseline `2027-02-16`, на C–S прогноз `2027-03-09` / Red / +21; `MS-UTL-PWR` baseline `2027-02-18`, на C–S прогноз `2027-04-15` / Red / +56; `MS-PS` на C и F — `2027-10-06` / Red / +21. Прямого ребра оборудование–веха нет. Цепочка панелей остаётся `EQ-CLN-01` → `ISS-CLN-01` → `MS-CLN-RDY`, плюс `RISK-CLN-01`.

## Состояние блока решений

Отдельного статуса у решения нет. Блок читает снимок целиком:

- `needed` — решений нет, `ISS-001` открыт, `EQ-HVAC-01` Delayed. Так на C и на D. Текст плашки — про запуск, не про панели.
- `recorded` — в снимке есть хотя бы одно решение. С F в списке есть `DEC-001`.

| Снимок | Что видит директор | Куда нажимает | Что узнаёт |
|--------|--------------------|---------------|------------|

## Проверка 2026-11-06

Единственная правка фикстуры — `TEX-D-CLN.causeImpact`: «Отставание монтажа панелей. Риск: чистые зоны не готовы к HVAC. Сдвиг поставки панелей — отдельное демосостояние, не причина монтажа». Связи исключения не менялись.

API и браузер на `http://127.0.0.1:3080`, сессия снимка без query:

- C: плашка «Требуется управленческое решение». Карточка `/issues/ISS-001` открылась со «Снимок C · на 01.03.2027». На шкале красные «Монтаж панелей… 09.03.2027» и «Энергоснабжение… 15.04.2027», запуск +21.
- D: та же плашка. Исключение показывает уточнённый текст. `/issues/ISS-CLN-01` — «Отставание монтажа панелей чистых зон», владелец Лебедева, снимок D. `/people/PER-07` в том же снимке, в проблемах `ISS-CLN-01`. `/equipment/EQ-CLN-01` — задержка, прогноз поставки 29.03.2027, +14. `/milestones/MS-CLN-RDY` — прогноз 14.05.2027, +14, красная, снимок D.
- F: в списке `DEC-001` «Утвердить ускоренную логистику AHU…», владелец Соколов. `/people/PER-01` в снимке F показывает `DEC-001`. `/milestones/MS-PS` — базовая 15.09.2027, прогноз 06.10.2027, +21, снимок F. Панели и энергоснабжение на шкале остаются красными с датами A01–A05.

Подписи плашки и блока исключений после этой проверки меняет B04–B06: на C и D заголовок «Требуется решение», на F — «Управленческие решения» и отметка «Решение записано», блок исключений — «Требует внимания». Журнал выше описывает экран на момент A06–A09.

# Комплект репетиции показа

> **certainty:** assumption
>
> E02 закрывается только после прогона другим участником и записи расхождений. Технический прогон автора ниже не заменяет эту репетицию.

**Запуск у ведущего.** С хоста из корня репозитория выполните `npm run dev` (см. `docs/10-operations/local-dev-and-demo.md`): поднимается docker compose на loopback.

**Доступ.** Адрес `http://127.0.0.1:3080` открывается только на том компьютере, где запущена демо-сборка; с другой машины по этому адресу зайти нельзя. Иного известного «удалённого» адреса для показа нет.

**Снимок.** Канон — номер **01…19**; в UI — тот же номер **01…19** . Хранится в sessionStorage вкладки, не в URL. Пустая сессия → **01** (01). Снимок **03** (03) участник выбирает сам. Кнопка «**Снимок**…»: например «Снимок **03** · 01.03.2027 · Срыв и давление». В списке — номер, дата и контекстная строка (для F: «Управленческие решения»). После выбора **06** (06) фаза на кнопке — «Управленческие меры»; карточка на дашборде — **«Прогноз и решение»** (не путать с пунктом сайдбара «Решения»).

**Узкое окно.** Ниже 1024px боковая колонка не стоит в ряду. Кнопка «**Открыть меню**» / «**Закрыть меню**» открывает те же разделы поверх страницы; селектор снимка остаётся в верхней панели. На обычном окне показа сайдбар снова в потоке, 240px, кнопки меню нет. Это отдельное правило узкой ширины. Открытая диагностика F07 — про кнопку сворачивания уже свёрнутого сайдбара — этим меню не закрывается.

**Старт (портфель, снимок 03).** Откройте главный маршрут: в боковой панели нажмите «**Дашборд**» — откроется `/`, параметр `?program=` в адресе не должен оставаться, заголовок шкалы — «**Вехи портфеля**», номер выбранного снимка на кнопке «Снимок…» сохраняется. В верхней панели откройте «**Снимок**…» и выберите **03** с датой **01.03.2027** (в подписи варианта — в том числе про HVAC / Production Start).

**Календарный план на снимке 03.** В боковой панели откройте «**Календарный план**». Если на кнопке снимка не **03**, выберите **03** (пустая сессия начинает со снимка **01** и режима «**Разделение**»). Режим уже «**Разделение**»: три иконки без текста на кнопках, нажата «**Разделение**». «**Временная шкала**» оставляет только диаграмму — для этих строк её не нажимайте. Первая строка — «**Внутренняя отделка и чистые помещения**», в колонке **ИСР** код **8**; кода AN-08 в ИСР нет. Если шеврон предлагает развернуть — разверните. Вторая строка — «**Чистые помещения классов C/D**», ИСР **8.2**; разверните, если свёрнута. Предупреждение — иконка: наведите курсор или переведите фокус, имя «**Отставание, 3 нед.**», в ячейке этой фразы нет. Третья строка, «**Сэндвич-панели и герметизация**», — **0%** (полоса и процент; это не «нет данных») и без верхней полосы. Четвёртая, «**Фальшполы и потолки**», — **40%**: верхняя полоса — база, нижняя — прогноз. Сравнение уже «**Базовый план / прогноз**». «**Базовый план / факт**» не включайте. Пятая строка — ромб «**Монтаж панелей чистых зон завершён**». Прокрутите список до «**Подготовка зоны монтажа**» (**100%**): шкала едет вместе со списком, рядом стрелки. Поиск по коду WK-01 стрелки убирает. Вернитесь на «**Дашборд**» и продолжайте маршрут ниже.

**Шаг к странице программы.** В блоке «Состояние по программам» нажмите «**Строительство**» — заголовок шкалы меняется на «**Вехи программы**». Затем нажмите ссылку «**Перейти к программе**» — откроется `/programs/PRG-CON`. Снимок остаётся **03**. Заголовок экрана (название страницы) — «**Строительство**».

**Проблема на снимке 04.** На этой странице программы снова откройте «**Снимок**…» и выберите **04**, **20.03.2027**. В блоке «**Текущие проблемы**» найдите ссылку «**Отставание монтажа панелей чистых зон**». Это **не** жирный заголовок исключения на дашборде портфеля — там другая формулировка («**Чистые зоны не готовы к HVAC**»); для проверки формулировки про панели **не** переходите на дашборд за этим заголовком. На снимке **03** в «Текущие проблемы» указано, что открытых проблем нет. Откройте ссылку «Отставание монтажа панелей чистых зон», затем строку «**AN-08 · Внутренняя отделка и чистые помещения**».

**Проверки на карточке проекта.** Убедитесь: владелец «**Лебедева Ольга Викторовна**», та же проблема, в тексте есть фраза о том, что **поставка не является причиной** отставания монтажа. Подпись к оборудованию — «**Панели чистых помещений**».

**Возврат без подсчёта «Назад».** Ориентируйтесь по **названиям экранов**, а не по числу нажатий «Назад» в браузере, если вы заходили в дополнительные разделы.

- С экрана карточки проекта «**AN-08 · Внутренняя отделка и чистые помещения**» нажмите ссылку «**Строительство**». Вы попадёте на экран программы «**Строительство**». Снимок остаётся **04**.

- Если вы открыли экран оборудования «**Панели чистых помещений**»: на нём нет ссылки обратно на карточку проекта. Нажмите «Назад» в браузере **один раз** — вы вернётесь на карточку «**AN-08 · Внутренняя отделка и чистые помещения**», снимок **04** сохранится. Далее снова используйте ссылку «Строительство», как в первом пункте.

**Снимок 06 / F (основной маршрут с экрана программы).** Находясь на экране программы «**Строительство**», нажмите «**Дашборд**»: `/`, «**Вехи портфеля**», `?program=` сбрасывается, **номер снимка** на кнопке сохраняется (останется **04**/D, пока не смените). Откройте «**Снимок**…» → **06**, **20.04.2027** (контекст «Управленческие решения»). В карточке **«Прогноз и решение»** найдите **DEC-001** и текст, что запись решения **не устраняет** отклонение прогноза; при необходимости откройте сайдбар **Решения**. В блоке «**Запуск производства**» — **06.10.2027** и **+21 день**.

**Если сбились с маршрута.** В боковой панели нажмите «**Дашборд**»: откроется `/`, выбранная программа сбросится, номер снимка на кнопке сохранится. Запишите каждое расхождение с ожидаемым поведением по шаблону, который пришлёт ведущий, и верните таблицу ведущему. Хранилище браузера не очищайте: старт сценария делается только действиями в интерфейсе.

## Памятка ведущему

- **Запуск:** из корня репозитория `npm run dev` (docker compose на loopback, см. `docs/10-operations/local-dev-and-demo.md`). Открывать у себя только `http://127.0.0.1:3080`; другой ПК по сети этот адрес **не** увидит, известного удалённого URL для сборки нет.
- **Старт участника на 03 без программы:** при чистой сессии сначала снимок **01**; участник через «**Снимок**…» выбирает **03** (01.03.2027), при необходимости «**Дашборд**» даёт `/`, «**Вехи портфеля**», без `?program=`.
- **Сбой маршрута:** «**Дашборд**» → нужный снимок → «**Строительство**» → «**Перейти к программе**».
- **Календарь на 03:** «Календарный план» → если номер не 03, выбрать 03 → остаться в «Разделение» (иконка уже нажата; «Временная шкала» прячет таблицу) → ИСР 8 и 8.2, предупреждение — иконка с именем «Отставание, 3 нед.» по наведению или фокусу, 0% и 40%, ромб вехи, верхняя база и нижний прогноз на 40%, сравнение «Базовый план / прогноз», WK-01 на 100% и стрелки рядом → «Дашборд» и дальше маршрут. Подробности — [шпаргалка](../guides/how-to/demo-v1-live-presentation.md#иерархия-календарного-плана).
- **На D показать:** в программе «Строительство» ссылка в «**Текущие проблемы**» про отставание монтажа панелей, строка **AN-08**; не вести за жирный заголовок исключения на портфеле («Чистые зоны не готовы к HVAC») ради формулировки про панели.
- **На 06/F показать:** карточка «**Прогноз и решение**» с **DEC-001** + honesty; «**Запуск производства**» — **06.10.2027** и **+21 день**.

## Запасной сброс

Если селектор не ставит C или программа не снимается, в консоли вкладки (**только ведущий**):

```js
sessionStorage.setItem('ppc.demo.snapshot', 'C');
sessionStorage.removeItem('ppc.demo.notificationRead');
localStorage.removeItem('ppc.demo.notificationPopup');
location.assign('/');
```

Пустое `ppc.demo.snapshot` поднимает снимок 01, не C. После сброса участник всё равно проверяет адрес без `?program=` и снимок 03 на кнопке снимка.

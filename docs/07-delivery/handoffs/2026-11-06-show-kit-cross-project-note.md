# Заметка для будущего обновления комплекта показа

Это не передача задачи. Агент №1 забирает текст после завершения своей текущей работы. Комплект показа, репетиция и общий план этим файлом не меняются.

## Шаг

На снимке C раскройте две ветки:

1. Группа «Внешние сети и энергоснабжение», этап «Электроснабжение».
2. Группа «HVAC и системы подготовки воздуха», этап «Монтаж AHU».

Между ромбом «Энергоснабжение обеспечено» и началом полосы «Подключение к сетям» видна одна линия. Её название для показа: «Межпроектное предшествование, тип не указан».

Четыре типизированные стрелки относятся к отдельному кластеру WK. Это связи работ чистых помещений («Подготовка зоны монтажа», «Разметка зон чистых помещений», «Монтаж панелей чистых помещений», «Герметизация стыков», «Приёмка участка»), не линия энергоснабжения и HVAC.

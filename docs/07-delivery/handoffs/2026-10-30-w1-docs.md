# Handoff: W1-Docs фундамент документации

## Мета

- **От:** W1-Docs
- **Кому:** следующие волны (website/Docusaurus, delivery, engineering)
- **Дата:** 2026-10-30
- **Область изменений:** `docs/**` только

## Цель волны

Создать полный фундамент документации по согласованному плану: стандарты, шаблоны, портал, product seed, ADR, quality/AI политики, handoff — без выдуманных FR/GMP и без правок вне `docs/**`.

## Сделано

- Дерево `docs/` с README в каждом разделе
- Standards: documentation-standard (status≠certainty, запрет AI auto-approve), terminology
- Набор `_templates/*`
- Portal: home, how-to-use, research-and-decisions, access-and-security
- Product: vision/scope (hypothesis), stack, demo-v1, persistence-transition
- Architecture: arc42 subset + ADR 0001–0003
- Delivery/quality/AI-engineering seed + guides README (Diátaxis)
- Этот handoff

## Не сделано / вне scope

- `website/` / Docusaurus scaffolding
- Docker / Compose / Caddy файлы
- OpenSpec содержимое, `AGENTS.md`, `package.json`, `.cursor/rules`
- `final-report.md` (W3)
- Любые выдуманные pharma/GMP REQ
- Enforcement тестов в приложении

## Блокеры

- Нет (в рамках scope W1-Docs). Ожидание: другие волны не должны править фундамент docs без handoff/ADR при смене решений.

## Рекомендации следующей волне

1. Не изобретать REQ — ждать источников; использовать шаблоны.
2. При создании сайта docs — только потреблять `docs/**`, не дублировать контент.
3. Реализацию Compose/proxy вести согласно ADR-0003, не меняя docs ради «как получилось», без нового ADR.
4. Соблюдать запрет AI: no auto-approve, no hypothesis→fact.

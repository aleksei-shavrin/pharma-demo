## 2. Observations from studied sources

- Approved shell already separates Page Surface from chrome.
- Dashboard blocks are question-driven; KPI ≥4 or omit.
- Status allowlist is narrow; Closed/Amber not Must.
- Schedule forbids Activity/WBS/CPM/dependency visuals.
